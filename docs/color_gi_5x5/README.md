## 与 Color_GI 不同

V1.0 检查 GI_5x5 自己的 `ratio_open_mode`，并调用 `test_roi_colorratio_5X5`。示例假设 Skip=0、ROI=5×5、开关为 1。Basic.data 中 RAW=3840×2160 RG Bayer，分成每通道 1920×1080；假设每块 384×216=82944 像素，共 25 块。按行优先从 0 编号，四角及中心是左上 0、右上 4、中心 12、左下 20、右下 24。

共用函数仍计算所有 25 块；随后读取五点 GG 映射。本教程仅模拟五点，其余 20 块未模拟。每块 Gr、Gb 的和各从 0.1 开始，普通情况返回：

```text
绿色平均和 = (Gr 和 + Gb 和) / 2
绿色相对差 = |Gr 和 − Gb 和| / 绿色平均和
```

这不同于 Color_GI 的 `Gr和/Gb和` 和对 1 的极值偏离，也不是 DN 直接差。每点映射值分别与该位置的 `TargetGI_*` 上限比较；任一项严格大于就失败，相等不失败，没有下限检查。不加 ColorRatio offset；ColorRatio 的 GG target 仅参与映射键的构造及查找，不是 GI_5x5 的阈值。

## 虚构五点及上限

各点 Gb=200 DN；每块通道内像素取固定值以便复算，不是实测。五个上限完全为教学假设。

## 前置与异常路径

- 共用函数要求先前 Light_Response 的 `mean_gr_roi>0 && mean_gb_roi>0`；不要求 Light_Response 子项通过，也不检查 ColorRatio 的开关。不同于 Color_GI，此函数没有 Gr>10 的额外检查。
- 若任一前置均值不大于零，五点映射为 −1，V1.0 仍把这些值与上限比较。上限均为正时 −1 不触发超限，子项保持初始通过；**不等于有效测量**。
- 底层若 `Gb和×100 < Gr和` 则 GG 置 100；五点映射随后将 >10 的值转换为 −1。极端数据也可能在正上限下不触发失败，需核查测量有效性。上限如为负，比较结果可能不同。
- 区域数或尺寸不合法可能造成除零、空向量或索引错误；源码入口没有完整保护。ColorRatio 的 target 作为 `QPair` 键同样可能受配置数据影响。
- V1.0 返回一个初始 true、bin 1、grade 0、g_msg=true 的子项；开关关闭时设 g_msg=false。未知版本返回 false、g_msg=false。调用方 `insert` 追加向量，最终 bin 另由其他子项共同决定。
