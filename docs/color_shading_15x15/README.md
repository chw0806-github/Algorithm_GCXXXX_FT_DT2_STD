## 基本步骤

假设 RAW 为 Basic.data 中的 3840×2160 RG Bayer，四通道各为 1920×1080。假设 15×15、Skip=0，每块为 128×72=9216 个通道像素，共 225 块；中心行、列均为 7（从 0 开始）。参数名称虽含 15×15，实际行列数仍来自配置。

`TestFunc_LSC` 逐块对四个通道计算均值，然后求 `R_mean × B_mean / (Gr_mean × Gb_mean + 1e−8)`。这不是其他 Shading 教程的 RG/BG 公式，也不加通道和的 0.1。EPS 同时用于后续角和边的比例比较，并不是有效数据校验。

四角分别取 2×2 块比例的平均；按源码方向计算左上/左下、左上/右上、左上/右下、左下/右上、左下/右下、右上/右下，每项为 `abs(前者/(后者+EPS)−1)×100`，取最大得到 `DiffCorner`。

四边则在边界上以中心索引为基准，各取连续 5 块比例的平均（中心索引被限制在 `[2, count−3]`）。上下差为 `abs(Top/(Bottom+EPS)−1)×100`，左右差为 `abs(Right/(Left+EPS)−1)×100`，取两者最大为 `Maxdiff`。除法方向不能交换。

## 虚构图像

所有区域假设 Gr=Gb=200、B=120；普通区域 R=100。左上、左下、右上、右下的 2×2 区域 R 分别为 80、90、100、120；上、下、左、右边中段各 5 块 R 分别为 100、80、100、110。角与边中段不重叠，所有区域的模拟值均已定义。四角平均比例约 0.24、0.27、0.30、0.36，最大角差约 33.3333%；上、下、左、右比例约 0.30、0.24、0.30、0.33，上下差约 25%、左右差约 10%，边差约 25%。计算保留 EPS 与未舍入值。

假设上限为 30% 和 20%，两个指标均严格超限，V1.0 会赋予假设的失败 bin 和 grade；等于阈值不失败。此结论不代表真实配置、实测或最终 bin。滑杆只修改最后一幕的右下角和下边中段 R 值。

## 注意源码异常路径

- 行列数小于 5 或总数不合法时 helper 返回 −1，**没有设置输出**；调用方没有检查返回值，直接读取未初始化的两个 `double`，产生未定义行为。
- `GetROIChannelMean` 只检查 ROI 末端是否大于图像尺寸，等于边界可用；越界返回 −1。它没有单独检查负起点和非正 ROI 尺寸；零面积可能出现除零，负索引也可能访问无效内存。无效均值未被 helper 检查，EPS 不保证数据有效。
- V1.0 初始子项为 true、bin 1、grade 0、`g_msg=true`；当 open_mode 不为 1 时直接返回此初始化结果，不会改为 `g_msg=false`。未知版本分支返回 false 且 `g_msg=false`。初始通过不证明有效测量。
- 加载器读取 MA 的 bin/grade，但本函数只返回一个子项且不使用它们。传入 `PixelBitCnt=8`、`debugmode=false` 和 `msg`，helper 的正常计算没有使用前两项，调用方也没有输出 helper 生成的 `msg`。
- 最终 `insert` 只是追加子项，最终 bin 由后续汇总决定。
