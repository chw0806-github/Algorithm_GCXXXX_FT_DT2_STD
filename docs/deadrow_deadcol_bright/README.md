# 白帧坏行坏列 Deadrow_Deadcol_bright

动画页和静态分镜页顶部均展示本示例对应的 `.data` 与 `Basic.data` 原文（框内可滚动）；静态分镜每幕也展示对应源码摘录。配置为 GC8613T 白帧示例，不等于实测数据。

- 动画：`index.html`（支持离线打开）；不执行脚本时可阅读 `storyboard.html`。
- 14 幕从行列概念、逐像素求行均值、上下邻行、比例差、扫描、DOL、半线均值与二次差，讲到边界和 bin。滑杆是两个独立目标线算例，背景两侧均值假设为 200，其他线、其他通道、DOL 和断线计数均假设为零；并非完整原始图像处理。

## 代码流程（V1.0）

1. 白帧已拆分为 R、Gr、Gb、B 四通道；行检测、列检测各自启动四个通道线程。
2. 每行/列求均值，再与两侧各 `radius=5` 条邻线的平均值比较。比例模式下计算两侧相对差，取最大值；严格大于 TA 阈值则计数。边缘邻线不足时，该侧使用当前线均值；任一侧邻近均值为 0 时两侧比例差和最终差都记为 -1。
3. 另外检查线内像素样本标准差（DOL，除以 N−1），以及半行/半列均值序列的二次差（断线）；超限分别计数。
4. 任一类计数大于 0 即失败。代码依次处理列、行、DOL、断线；后项的 grade 须严格大于当前 grade 才会覆盖结果。还有列、行的低等级 MA 分支，见源码。

## 教学算例

- R 通道一行 1920 像素：180～199 DN 共 20 个不同亮度，按顺序重复 96 次，均值 189.5 DN。上方 5 个行均值为 196、198、200、202、204；下方为 206、208、210、212、214。两侧平均分别为 200 和 210，两侧比例差为 5.25% 和约 9.76%，取大值超过 2.5%。重复分布只是便于复算，并非算法限制；这只演示目标行，不推断完整图像计数。
- DOL 是独立算例：50～59 和 241～250 DN 共 20 个不同亮度，各 96 个，平均 150 DN，平方偏差和 17526720，样本标准差 `√(17526720/1919)≈95.57 DN`，高于 R 阈值 80。
- 断线是另一独立算例：连续三行左半均值 198、201、220，相邻变化为 3 和 19，二次差 16 高于阈值 10，计数加一；右半和列上下半也分别计算。
- `true` 对应 `log_flag`，控制代码中受该条件保护的日志追加，不改变判定。

## 示例配置

`GC8613T/CP_SPEC/param_4l_f_bright1_normal_30fps/LineDefect.data`：`open_mode=1`、`radius=5`、四通道行 TA/MA 阈值均为 0.025，列 TA/MA 均为 0.030。DOL 阈值 R/B 为 80、Gr/Gb 为 90；断线阈值为 10。异常列常见分支 bin 2208 / grade 7；异常行 2210 / 7；DOL 2212 / 6；断线 2213 / 5。在本配置 TA 和 MA 阈值相同时，TA 已触发意味着最大差达到对应 MA 值。配置不同，结果可能不同。

## 源码位置

- `TestItems/BrightTest.cpp`：调用及最终子项汇总。
- `FTAlgorithm.cpp`、`Params/parammanage.cpp`：V1.0 / V1.1 配置加载及版本选择。
- `Params/algorithmitems.cpp`：V1.0 的结果判定、grade 和 bin。
- `Params/testitems.cpp`、`Params/multithread.cpp`：线程及四通道结果汇总。
- `Params/cpalgorithmraw.cpp`：行、列的均值、邻域差、DOL 与断线计算。
