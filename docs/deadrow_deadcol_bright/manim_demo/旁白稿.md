# 坏行检测样片 · 旁白稿

> 建议配合画面分段录制并调整停顿；这是文字稿，不是已生成的音频。数字是模拟值。

1. 白帧拆分后，我们先看 R 通道。示例中这张图有一千九百二十列、一千零八十行。黄线标出的是其中一条目标行。
2. 这一行包含一千九百二十个像素。为了方便计算，假设前一半像素的亮度都是一百八十，后一半都是二百。把所有亮度加起来，再除以一千九百二十，得到目标行均值一百九十。
3. 现在找目标行的邻居：上面五行、下面五行。目标行本身不算进去。假设上面五行的均值是二百，下面五行的均值是二百一十。两侧要分别计算。
4. 目标行与上方的差是百分之五；与下方的差约为百分之九点五二。取两者较大的值，约为百分之九点五二。
5. 配置的行阈值是百分之二点五。因为百分之九点五二严格大于阈值，这一条目标行记为异常。等于阈值时不算超限。
6. 实际检测会对各个通道和各条行重复这个过程。本例只讲一个目标行，不代表整张图像的结果。列、DOL 和断线检查需要另行讲解。
