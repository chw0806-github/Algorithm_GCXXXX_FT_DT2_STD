## 假设算例

1. 顶部 R 行 1920 个像素：180～199 DN 的 20 个值按顺序重复 96 次；和为 363840，均值 189.5 DN。动画只示意前 10 个位置并直接显示整行总和与均值；真实是同一行。该重复分布不是算法要求。
2. 向内下方 5 条邻行的均值分别为 196、198、200、202、204 DN，平均为 200；比例差 `|189.5−200|/200 = 5.25%`。这是行均值，不是 5 个像素。底部向上；列检测中左侧向右、右侧向左。参考均值为零时，此版本比例除法没有单独保护。
3. R 行 TA 为 2.5%，差值必须**严格大于** TA 才计数；有行计数后，根据通道最大差与行 MA 3.5% 比较，**大于或等于**选择 2216 / grade 6，否则选 2217 / grade 2。5.25% 在假设其他通道、边缘线及 DOL 均无异常时对应 2216 / 6。
4. 独立列算例：假设目标列均值 192、向右 5 列均值 196、198、200、202、204，参考平均 200，比例差为 4%。超过 R 列 TA 3% 且达到 MA 3.5%，假设仅此列异常为 2214 / 6。每列 1080 个像素，未构造完整列数据。
5. 独立 DOL 行算例：50～59、241～250 DN 每个值各 96 次，共 1920 个；均值 150，平方偏差和 17526720，样本标准差 `√(17526720/1919)≈95.57`，严格大于该配置的 50。DOL 看同一选中线内部，不是前面邻线比例。

## 优先级与代码风险

先处理列，再处理行，最后处理 DOL。行分支**先**用高等级 `grade_dead_row_` 与当前 grade 严格比较，进入后才按 MA 确定高或低等级；DOL 以其 grade 与当前结果严格比较。因此不能简单概括为所有结果的固定排序。子项结果还需与其他测试项汇总。

`Params/testitems.cpp` 的 `test_edge_row_defect_bychannel` 和 `test_edge_col_defect_bychannel` 在 delete 线程对象之后，日志代码仍读取其成员，是**释放后读取**，会导致未定义行为；应由开发人员检查修复并验证。本动画只讲解源码逻辑，未修改算法，不能保证实际运行结果。
