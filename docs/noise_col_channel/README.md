# 暗场列通道噪声 Noise_Dark_Col_Channel

[动画](index.html) · [静态分镜](storyboard.html)。18 幕讲解多帧 STD、四个 Bayer 位置的列均值、最大列与通道平均之差和阈值；带逐幕源码、配置原文和模拟交互。动画可以单独打开，分镜不执行脚本。

## 不看公式，先记住

- 先看 **时间方向**：固定一个像素，看它在多帧中的波动，得到一个 STD。
- 再看 **空间方向**：固定一种 Bayer 位置的一列，把不同位置的 STD 求平均，得到一个列均值。
- 同通道的各列均值中，找最大值减去所有列的平均值；四通道的差值取最大，再对照上限。这样衡量的是“有没有某列比同通道整体更突出”，不是判断每列是否完全没有噪声。

动画中的 4 个 STD 的列平均和 4 列对比例只是独立的缩小示例，不是后面 1920 列主例，也不是实测。

## 实际示例与进入条件

GC8613T 的 `param_4l_f_dark1_normal_30fps/Channel_Noise.data` 为 `Column_Noise_Max=3.2`、`bin=2075`、`grade=5`、`open_mode=1`；`Basic.data` 为 3840×2160、RG Bayer。该目录有 V1.0 文件，没有 `Channel_Noise_V1.1.data`。加载时先尝试 V1.0 后尝试 V1.1，文件打开后即赋版本，后续解析仍可能失败；实际加载状态需运行时确认。

暗噪声入口检查帧数大于 1、尺寸为正及 datatype 为 8/10/12/14/16，再原位掩码转换并计算共享 STD 图。调用结果与 Read、Row、ColRTS 三个子项共同送去最终 bin 汇总；这里的模拟失败不一定是设备最终 bin。关闭或未知版本时 `g_msg=false`，不能视为有效测量。

## 算法与虚构数据

1. 输入为每帧连续的双字节像素，每一帧的相同坐标构成时间序列。计算样本标准差 `sqrt(sum((x−mean)²)/(N−1))`；各坐标 STD 构成原尺寸图。四线程各处理行区段，而不是先分四种颜色。
2. V1.0 每次按 2×2 的四个奇偶位置取数，每类位置分别对各列的 STD 求平均。RG 排列下分别是 R/Gr/Gb/B，每类 1920 列，每列 1080 个值。函数本身固定位置与标签，不根据 Bayer 重映射；其他排列不能直接照搬颜色名称。
3. 四类分别求 `最大列均值 − 全部列均值的平均`，再取四个差的最大值。严格大于配置上限且大于零才失败；等于上限不失败，比较使用未舍入值。日志 dB 是另一种显示，不是 V1.0 的判定量。
4. 假设 4 帧、10 位，普通列的每个位置为 97、99、101、103，STD≈2.58199；R 第 301 列为 91、97、103、109，STD≈7.74597，其余 1919 列为普通列。R 全部列的平均≈2.58468，差≈5.16129，假设其他位置各列均相同，四者最大即为 R 差。超过 3.2，模拟子项失败 2075/5。画面只画局部；这些图像、帧数和结果均为教学假设，不是实测。
5. 互动假设目标列的每点帧值为 `100−3k, 100−k, 100+k, 100+3k`，其他列不变。k=1/2/3/4 可观察变化；不会修改配置或执行真实图像检测。

## 版本与边界

- V1.1 优先判断 Level 2，未达到再判 Level 1；该目录无其专用配置，本教程不推断阈值。
- 四线程的起点用整数 `h/4`、`h*2/4`、`h*3/4`，每段只处理 `h/4` 行；不整除 4 可能留空，须核查。按 2×2 访问要求偶数宽高，否则可能越界，而入口只检查尺寸为正。
- 掩码转换虽支持多位深，但 STD 读取高字节只取低 2 位，实际最多取低 10 位，dB 计算也固定除以 1023；其他位深不能假定完整保留。
- B 通道结构化日志的最大值字段引用了 R 的最大值；普通消息日志该字段正确，判定仍按 B 向量算。代码记录的最大位置是向量索引乘 2，奇列位置的物理列需注意偏移。
