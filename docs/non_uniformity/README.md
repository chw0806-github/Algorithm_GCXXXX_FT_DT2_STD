# 白帧不均匀性 Non_Uniformity

- 动画：`index.html`（双击或通过本地服务打开）
- 静态分镜：`storyboard.html`（无脚本也可阅读）
- 前 6 幕用固定的 4 像素例子逐步解释计算；后 4 幕用另一组 4×3 格子解释汇总与判定。
- 拖动滑杆或点击预设，改变后一组示意网格左上格的百分比；滑杆不会改变前面的 4 像素例子。

## 手算一个格子

假设某个格子仅有 4 个像素，亮度依次是 180、190、210、220 DN：

1. 像素均值：`(180 + 190 + 210 + 220) / 4 = 200 DN`。
2. 各像素减去均值：`−20, −10, +10, +20`；平方后为 `400, 100, 100, 400`。
3. 平方的平均是 `1000 / 4 = 250`；总体标准差 `√250 ≈ 15.81 DN`。
4. 该格局部不均匀性：`√250 / 200 × 100 ≈ 7.91%`（使用未四舍五入的标准差）。

这 4 个像素是教学简化。实际示例配置每个通道格是 48×27，即 1296 个像素；同样逐格计算。求百分比时，若均值 ≤ 0.001，只有分母设为 0.001，标准差仍使用原始均值。

## 如何试滑杆

下一组独立的 4×3 格子里，11 个为 2%，左上格由滑杆设置：

| 左上格 | 发生什么 | 子项 bin |
|---|---|---|
| 2% | 四项均未超限 | 1 |
| 31% | 最大值超过 30%，均值仍未超过 5% | 2204 |
| 39% | 均值超过 5%，最大值也超限；同 grade 时保留先判断项 | 2203 |
| 53% | 左右和上下镜像差也超过 50；前面的均值、最大值已超限 | 2203 |

例如默认 12% 时，格子百分比的平均值是 `(12 + 11×2) / 12 ≈ 2.83%`，最大是 12%；左上与右上、左上与左下的差都是 10 个百分点。这与上面的 4 像素算例互不相连。

## 流程

1. 白帧测试先拆出 R、Gr、Gb、B；四个通道各自以完整格子处理。
2. 每个格子计算像素的均值和总体标准差，局部不均匀性 = 标准差 / 均值 × 100。均值不大于 0.001 时分母取 0.001。
3. 对各格的百分比求平均和最大值；将每格与其左右、上下镜像格的百分比作差，分别取最大绝对差。
4. 四项指标依次和各通道配置的上限比较，任一严格大于上限即失败。后续失败项只有 grade 严格更高才能覆盖当前 bin。

示例配置 `GC8613T/CP_SPEC/param_4l_f_bright1_normal_30fps/NonUniformity.data`：RAW 格 96×54（通道图上为 48×27），各通道平均上限 5、最大上限 30、左右差和上下差上限各 50；对应 bin 2203、2204、2205、2206，grade 均为 6。其他配置可能不同。

动画的 4×3 网格及百分比均为教学示意，只模拟一个通道、假设其他通道通过。格子数量和数值不是实际测量。若版本不匹配或该项未开启，处理路径不同；最终 bin 还要在测试项之间汇总。
