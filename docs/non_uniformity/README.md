## 完整的 1296 像素算例

每个通道格 48×27 = 1296 像素。演示假设其中亮度 180、190、210、220 DN 各有 324 个：

1. 均值：`324 × (180+190+210+220) / 1296 = 200 DN`。
2. 对这四类像素，减去均值后的偏差分别为 `−20, −10, +10, +20`；平方分别为 `400, 100, 100, 400`。
3. 总体方差：`324 × (400+100+100+400) / 1296 = 250`；总体标准差 `√250 ≈ 15.81 DN`。
4. 该格局部不均匀性：`√250 / 200 × 100 ≈ 7.91%`。

若均值 ≤ 0.001，源码仅把计算百分比的分母设为 0.001；标准差仍由原始均值计算。

## 1600 格互动模型

网格完整显示一个通道的 40×40 格。左上格和其余 1599 格的百分比分别由两个滑杆控制；这只是计算结果的模拟，不由前面的像素算例自动生成。其余三个通道假设通过。

| 左上格 | 其余 1599 格 | 指标与结果 | 子项 bin |
|---|---|---|---|
| 2% | 2% | 四项均未超限 | 1 |
| 31% | 2% | 最大值超过 30%，均值未超过 5% | 2204 |
| 39% | 6% | 均值和最大值都超限；同 grade 保留先判断项 | 2203 |
| 53% | 2% | 镜像差及单格最大值都超限，最大值先判断 | 2204 |

默认左上 12%、其他格 2%：格子百分比的平均为 `(12 + 1599×2) / 1600 = 2.00625%`，最大为 12%；左上与右上、左上与左下的差都是 10 个百分点。镜像差比较的是两格的局部不均匀性，而不是亮度均值。

## 实际处理流程

1. 白帧拆出 R、Gr、Gb、B；四个通道分别以完整格子处理。
2. 每个格子计算像素均值和总体标准差，局部不均匀性 = 标准差 / 均值 × 100。
3. 每个通道对所有格的百分比求平均和最大值；对左右、上下镜像格的百分比作绝对差，分别取最大。
4. 四项指标依次和各通道配置上限比较，任一严格大于上限即失败。后续失败项只有 grade 严格更高才覆盖当前 bin。

`GC8613T/CP_SPEC/param_4l_f_bright1_normal_30fps/NonUniformity.data` 配置：RAW 格 96×54（通道格 48×27），各通道平均上限 5、最大上限 30、左右差和上下差上限各 50；对应 bin 2203、2204、2205、2206，grade 均为 6。图像尺寸和参数可能因配置不同而变化。版本不匹配或该项未开启时处理路径不同；最终 bin 还要在测试项之间汇总。
