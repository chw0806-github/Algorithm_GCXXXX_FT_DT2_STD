这一页在讲什么

Non_Uniformity 把四个颜色通道各自分格：每格计算标准差除以均值，得到局部波动百分比；再比较格子的平均、最大及对称位置差异，按配置判断是否超限。

动画无法启动时，可看不依赖脚本的静态分镜。

数量按 GC8613T 配置：3840×2160 RAW、每通道 1920×1080、每格 48×27、每通道 40×40 格。 所有数值为模拟；默认把像素算例结果四舍五入后放到左上格，其余格假设为 2%；拖动滑杆不会改变像素。
